# Security Policy

## Supported Versions

Security updates are provided for the latest release line on `main`.

## Reporting a Vulnerability

If you discover a security vulnerability in KMedia (such as unsafe archive extraction in `.jwpub` / `.jwlplaylist` parsers, path traversal, or WebSocket authentication issues), please report it responsibly through GitHub's private security advisory feature on `matheuscardosos/kmedia` instead of opening a public issue.

Please include:

- A clear description of the issue and affected component
- Steps to reproduce or a minimal proof of concept
- Any suggested mitigation if known

I will review reports promptly and coordinate a fix before public disclosure.
